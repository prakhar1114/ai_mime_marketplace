# play-a-song-on-spotify

Play a requested song on Spotify via the Spotify Web Player using the user's
already-logged-in browser session. Accepts a natural language query and plays
the closest match on Spotify.

## Run it

The script uses browser-harness helpers which are pre-imported by the harness runtime, so run it through the harness:

```bash
./run.sh
```
