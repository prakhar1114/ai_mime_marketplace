# Fallback Plan

Intent: help the user complete the IRCTC booking form manually if the automation cannot continue.

- Ask the user to open https://www.irctc.co.in/nget/train-search in Chrome and log in manually.
- Enter the source, destination, date, passengers, train, and class from the provided inputs.
- Proceed only until the passenger details form is filled and ready for user review.
- Stop before payment, terms confirmation, or any irreversible booking action.
